# 🕐 Ora Analoge

Orë analoge e vizatuar me Canvas dhe JavaScript — tregon **orën reale** të pajisjes tënde, me akrepin e sekondave që lëviz butësisht, orë dixhitale dhe datë në shqip.

## 🚀 Si ta hapësh

Hap `index.html` në browser — demo-ja nis vetë dhe tregon orën aktuale. Nuk ka butona: ora është gjithmonë live.
